# 01: Pristine graphene bands

This is the smallest GRABNES band-structure calculation. It constructs a
two-atom pristine graphene cell and evaluates its two pi bands along the
`K - Gamma - M - K'` path.

## Run

Compile GRABNES from the repository root, then execute:

```sh
./run.sh
python3 plot.py
```

The plotting step requires Python 3 and Matplotlib. Install Matplotlib with
`python3 -m pip install matplotlib` if it is not already available.

`run.sh` writes the program log to `job.out` and GRABNES writes the band data
to `generate.bands`. `plot.py` creates `graphene_bands.png`. If a calculation
has not been run yet, the plotting script uses `reference/bands.dat`, so the
expected result can still be inspected.

If the executable is not at `../../lanczosKuboCode/bin/grabnes`, provide it
explicitly:

```sh
GRABNES_BIN=/path/to/grabnes ./run.sh
```

## Important input controls

- `TB.Hopping` sets the nearest-neighbor hopping in electronvolts.
- `Bands.NumPoints` controls the sampling density along each path segment.
- `Bands.Path` lists the high-symmetry points in reciprocal coordinates.
- `Prefix` determines the prefix of generated output files.

The reference data were generated by the pristine-band example used in the
Twistronics 2023 tutorial.
