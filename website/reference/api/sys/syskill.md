# `SysKill`

```{index} single: SysKill (subroutine in sys)
```

```fortran
subroutine SysKill(message, module, func, hold)
```

- **Module:** {ref}`sys <api-sys>`
- **Kind:** Subroutine
- **Source:** [`lanczosKuboCode/Src/MIO/sys.F90, line 72`](https://github.com/gjung-group/grabnes/blob/1e390c6ead7c835389ae89a599cb1f39e3fc691e/lanczosKuboCode/Src/MIO/sys.F90#L72)

Display an error notification and terminates the program. This function shows the module from where it was called, and, in DEBUG mode, the function inside that module. With 'hold' variable is possible to wait for a SysKillFlush call to terminate the program.

## Parameters

`message` : `character(len=*), intent(in)`
: Error message

`module` : `character(len=*), intent(in)`
: Module where the error occurred

`func` : `character(len=*), intent(in), optional`
: Function where the error occurred

`hold` : `logical, intent(in), optional`
: If true, the program continues executing

{ref}`SysPrint <api-sys-interface-sysprint>`, {ref}`SysPrintErrors <api-sys-sysprinterrors>`
